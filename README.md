# NovaTech — Modern Technology Landing Page

## About the Project
NovaTech is a modern and responsive technology landing page developed as part of the Oasis Infobyte Web Development and Designing Internship — Level 1, Task 1.

## Features
- Sticky navigation bar with Home, Features, About, and Contact links
- Hero section with a headline, description, and call-to-action button
- Feature cards highlighting performance, security, and responsive design
- About section
- Footer with contact and social links
- Responsive layout for desktop and mobile devices
- Smooth scrolling and consistent colour styling

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Project Structure
- `index.html` — Main webpage structure
- `style.css` — Styling and responsive layout
